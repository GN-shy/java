# StringBuilder

## StringBuilder 的基本概念

`StringBuilder` 是 Java 中的一个可变字符序列，可以理解为一个存储字符串内容的容器，主要用于提高字符串频繁拼接和修改时的效率。

特点：

- 可以不断添加、修改字符串内容。
- 可以添加字符串、数字、字符、布尔值等数据，添加时会转换成对应的字符串形式。
- 修改内容时，直接操作原对象，不需要反复创建新的字符串对象。
- 线程不安全，但在单线程环境下通常具有更高的执行效率。

String 与 StringBuilder 的区别：

```
// String：字符串内容不可变
String s = "Hello";
s = s + "Java"; // 拼接后产生新的字符串结果

// StringBuilder：字符串内容可变
StringBuilder sb = new StringBuilder("Hello");
sb.append("Java"); // 直接在原对象上追加内容
```

## StringBuilder 的构造方法

| 构造方法                           | 作用                                 |
| ---------------------------------- | ------------------------------------ |
| `public StringBuilder()`           | 创建一个空的字符串缓冲区             |
| `public StringBuilder(String str)` | 创建一个字符串缓冲区，并指定初始内容 |

代码示例：

```
// 创建空的 StringBuilder 对象
StringBuilder sb1 = new StringBuilder();

// 创建指定初始内容的对象
StringBuilder sb2 = new StringBuilder("Hello");

System.out.println(sb1); // 空字符串
System.out.println(sb2); // Hello
```

## StringBuilder 的常用成员方法

| 方法               | 作用                   | 返回值        |
| ------------------ | ---------------------- | ------------- |
| `append(任意类型)` | 在末尾添加数据         | StringBuilder |
| `reverse()`        | 反转字符序列           | StringBuilder |
| `length()`         | 获取当前字符序列的长度 | int           |
| `toString()`       | 转换为 String 类型     | String        |

### append() 方法

作用： 将指定数据添加到字符串缓冲区的末尾。

代码示例：

```
StringBuilder sb = new StringBuilder();

// 添加字符串
sb.append("红色");
sb.append("蓝色");
sb.append("绿色");

System.out.println(sb); // 红色蓝色绿色

// 添加不同类型的数据
StringBuilder sb2 = new StringBuilder();

sb2.append(10);
sb2.append('a');
sb2.append(12.3);
sb2.append(false);

System.out.println(sb2); // 10a12.3false
```

链式编程：

因为 `append()` 返回当前的 `StringBuilder` 对象，所以可以连续调用方法。

```
StringBuilder sb = new StringBuilder();

sb.append("Java").append("Python").append("C++");

System.out.println(sb); // JavaPythonC++
```

### reverse() 方法

作用： 将字符串缓冲区中的字符顺序反转。

代码示例：

```
StringBuilder sb = new StringBuilder("abcdef");

// 反转字符串
sb.reverse();

System.out.println(sb); // fedcba
```

### length() 方法

作用： 获取当前字符串缓冲区中的字符序列长度。

代码示例：

```
StringBuilder sb = new StringBuilder("Hello");

int len = sb.length();

System.out.println(len); // 5

sb.append("Java");

System.out.println(sb.length()); // 9
```

### toString() 方法

作用： 将 `StringBuilder` 对象转换为 `String` 类型。

代码示例：

```
StringBuilder sb = new StringBuilder();

sb.append("Hello");
sb.append("Java");

// 转换为 String 类型
String result = sb.toString();

System.out.println(result); // HelloJava
```

注意： `StringBuilder` 和 `String` 是不同类型，不能直接赋值，必须调用 `toString()`。

```
StringBuilder sb = new StringBuilder("Hello");

// 错误
// String s = sb;

// 正确
String s = sb.toString();
```

## StringBuilder 综合代码示例

```
public class StringBuilderDemo {
    public static void main(String[] args) {

        // 1. 创建 StringBuilder 对象
        StringBuilder sb = new StringBuilder();

        // 2. 链式添加数据
        sb.append("红色")
          .append("蓝色")
          .append("绿色");

        System.out.println(sb); // 红色蓝色绿色

        // 3. 获取长度
        System.out.println(sb.length()); // 6

        // 4. 反转字符串
        sb.reverse();

        System.out.println(sb); // 色绿色蓝色红

        // 5. 转换为 String 类型
        String result = sb.toString();

        System.out.println(result); // 色绿色蓝色红
    }
}
```

## StringBuffer

### StringBuffer 的基本概念

`StringBuffer` 也是 Java 中的可变字符序列，功能与 `StringBuilder` 基本相同。

特点：

- 可以直接修改字符串内容。
- 支持 `append()`、`reverse()`、`length()`、`toString()` 等方法。
- 线程安全：常用方法通过同步机制保护，适合多个线程共享同一个对象的情况。
- 由于存在同步开销，在单线程环境下通常比 `StringBuilder` 慢。

### StringBuffer 的构造方法

```
// 创建空的 StringBuffer 对象
StringBuffer sb1 = new StringBuffer();

// 创建指定初始内容的对象
StringBuffer sb2 = new StringBuffer("Hello");
```

### StringBuffer 的常用方法

`StringBuffer` 与 `StringBuilder` 的常用成员方法基本一致。

代码示例：

```
StringBuffer sb = new StringBuffer();

// 1. 添加数据
sb.append("Java");
sb.append("Python");

System.out.println(sb); // JavaPython

// 2. 获取长度
System.out.println(sb.length()); // 10

// 3. 反转字符串
sb.reverse();

System.out.println(sb); // nohtyPavaJ

// 4. 转换为 String
String result = sb.toString();

System.out.println(result); // nohtyPavaJ
```

### String、StringBuilder、StringBuffer 的区别

| 对比             | String             | StringBuilder        | StringBuffer           |
| ---------------- | ------------------ | -------------------- | ---------------------- |
| 字符序列是否可变 | 不可变             | 可变                 | 可变                   |
| 线程安全性       | 不可变，可安全共享 | 线程不安全           | 常用方法有同步保护     |
| 频繁修改的效率   | 通常较低           | 通常最高             | 通常低于 StringBuilder |
| 主要用途         | 存储固定字符串     | 单线程频繁拼接字符串 | 多线程共享可变字符序列 |

如何选择：

- String：字符串内容不需要频繁修改时使用。
- StringBuilder：需要频繁拼接、修改字符串时，优先使用。
- StringBuffer：多个线程需要共享并修改同一个字符序列，且需要方法级同步时使用。

核心记忆：

- `String`：不可变字符串。
- `StringBuilder`：可变字符串，效率高，线程不安全。
- `StringBuffer`：可变字符串，提供同步保护，通常效率略低。

实际开发中，普通的频繁字符串拼接场景通常优先选择 `StringBuilder`。
